# 주요 철학 저작 일괄 공개 대기 배치

작성·검수일: 2026-10-05 (Asia/Seoul)

## 현재 상태와 배포 경계

사용자의 최신 지시는 **대량 제작 후 나중에 한 번에 NAS 반영**이다. 이번 산출물은 로컬 콘텐츠만이며 전부 `draft`다. DB 접속·SQL 실행·마이그레이션 등록·GitHub push·PR·CD·NAS 접속·AtChaGong 중지를 하지 않았다. 기존 공개 글과 기존 마이그레이션은 수정하지 않았다.

`posts.json`은 40번 콘텐츠 교환 형식에 따른 산출물이며 관리자 API에 바로 보내는 DTO가 아니다. 실제 일괄 공개 승인을 받은 뒤, 기존 운영 데이터와 철학자 매핑을 검증하는 **새 트랜잭션 마이그레이션**을 별도 작성해야 한다. 이번 파일만으로 자동 배포되지 않는다.

## 편집 및 원전 대조

각 본문 슬라이드의 근거는 `posts.json → editorial.cardEvidence`에 절/권/스테파누스 번호로 적었다. 인용문을 새로 만들어 넣지 않았고 현대 한국어 번역문을 복제하지 않았다. 독립적으로 작성한 짧은 해설이며 원전의 모든 논증을 대체하는 전역·주석서는 아니다.

- 순수이성비판: [Meiklejohn 구영역 원전](https://www.gutenberg.org/cache/epub/4280/pg4280-images.html). 경험에서 시작함과 경험에 전적으로 기원함, 현상과 환상, 자유의 사유 가능성과 이론적 증명을 구분했다. 수학적/역학적 이율배반의 해법을 모두 같은 명제로 단순화하지 않았다.
- 실천이성비판: [Abbott 구영역 원전](https://www.gutenberg.org/cache/epub/5683/pg5683-images.html). Gutenberg 5682의 《정초》와 혼동하지 않았다. 자율을 기분대로 선택함으로, 신과 불멸의 요청을 과학적 증명으로 설명하지 않았다.
- 판단력비판: [Bernard 구영역 원전](https://www.gutenberg.org/cache/epub/48433/pg48433-images.html). 미·쾌적함·좋음, 숭고의 두 종류, 규정적/반성적 판단을 구분했다. 유기체의 목적론을 설계자의 이론적 증명이나 기계적 탐구의 포기로 제시하지 않았다.
- 정의론: 1971년 저작/1999년 개정판의 논의 범위를 사용했다. [출판사 서지 링크](https://www.hup.harvard.edu/books/9780674000780)는 자동 접근이 제한되어 전문을 읽었다고 주장하지 않는다. 공개된 [Rawls 연구](https://plato.stanford.edu/entries/rawls/), [원초적 입장](https://plato.stanford.edu/entries/original-position/), [분배정의](https://plato.stanford.edu/entries/justice-distributive/), [반성적 평형](https://plato.stanford.edu/entries/reflective-equilibrium/), [세대 간 정의 §4.4](https://plato.stanford.edu/archives/fall2020/entries/justice-intergenerational/)로 핵심 개념을 대조했다. 후대의 『정치적 자유주의』와 『공정으로서의 정의』의 정식을 이 책의 직접 문장처럼 제시하지 않았다. 숫자 비교는 편집자가 만든 예시이고, 무지의 베일을 무조건적인 최악 선택 전략이나 단순한 추첨으로 설명하지 않았다. 소득과 기회의 차이, 응분과 정당한 기대, 이론 설명과 편집자의 비판적 질문을 구별했다.
- 국가: [Jowett 구영역 원전](https://www.gutenberg.org/cache/epub/1497/pg1497-images.html)의 본문을 기준으로 ① I–II 367e ② II 368c–IV ③ V–VII ④ VIII–IX ⑤ X로 나눴다. 역자 서론을 플라톤의 대사로 인용하지 않았다. 기게스·동굴·에르의 이야기를 역사적 사실로 제시하지 않았고, 《파이드로스》의 마차 비유를 《국가》에 옮기지 않았다. 여성 수호자 논의가 현대적 성평등 전체는 아니라는 점, 가족/출산 통제와 검열의 강제성, 민주정 비판의 역사적·규범적 한계를 명시했다.
- 의지와 표상으로서의 세계: [Haldane/Kemp 구영역 원전](https://www.gutenberg.org/cache/epub/38427/pg38427-images.html)의 본편 I–IV를 두 편으로 나눴다. 영문 3권본의 Vol. 1이라는 표시와 독일어 저작 본편/보충편 구분을 혼동하지 않았다. 표상을 허구로, 의지를 단순한 결단력으로 설명하지 않았다. 본질에 관한 추론과 경험적 입증을 구별했고 §69의 자살과 의지 부정의 구별을 명시했다. 금욕론을 자해 권유나 치료 지침으로 제시하지 않는다. 후기 보충편 전부의 요약은 아니다.

## 이미지

74개의 서로 다른 실제 자료를 사용했다. 기존 로컬 자료 72개와 새 자료 2개이며 AI 생성은 0개다. 글 사이 재사용은 허용하지만 한 글 안에서는 표지·본문·출처 전부 다른 원본이다.

- 신규: 《판단력비판》 1794년 표제지(퍼블릭 도메인), Rijksmuseum의 후대 동굴 비유 판화(CC0). 원본 설명·이용 조건을 확인하고 로컬 JPEG를 직접 확인했다.
- 기존: 이미 수집된 자료의 저작자·라이선스·원본 URL·SHA256을 재사용했다. 원래 카뮈/논어 게시글의 설명을 그대로 가져오지 않고 이번 배치에 맞게 별도 캡션을 작성했다. 기존 이미지 메타데이터 파일은 수정하지 않았다.
- 기록: `image-provenance.json`의 74개 항목, 글별 `editorial.imageUses`, 앱 표시용 마지막 출처 카드에 저작자·원본·이용 조건·변경 사항을 보존했다.
- 도해/회화/사진을 철학자의 직접 예시나 실제 사건의 증거라고 주장하지 않는다. 중국 악기·회화, 후대 유럽 회화는 명시적으로 비교 자료로 설명한다.
- 파일명, SHA256, 원본 URL과 알려진 동일 원본 계열을 검사했다. 74개 이미지 연락표 4장을 육안으로 확인했고 새 이미지 2개는 개별 확인했다. 같은 그림의 크롭을 다른 원본으로 세지 않았다.
- 재현 도구: `review-images.ps1`. 연락표는 버전 관리에서 제외된 `.local/major-works-v9-review/`에 생성한다. 새 파일 재다운로드 도구는 `download-new-media.cjs`이며 기본 검증은 네트워크를 사용하지 않는다.

## 파일과 검증

- `*.authoring.json`: 편집 원본. 각 행은 이미지 참조/제목/본문/근거를 담는다.
- `posts.json`: 14편의 교환 형식 콘텐츠.
- `catalog.json`: 사상가 참조 키. `existing`은 소스 기준이며 운영 DB 조회 결과가 아니다.
- `manifest.json`: 편별 제목·상태·장수와 배포 금지 상태.
- `preview.html`: 로컬 이미지와 본문을 함께 읽는 미리보기. 출처는 펼쳐 보기로 접었다. 실제 iOS UI를 렌더링한 것은 아니다.
- `build.cjs`: 오프라인 구조·중복·권리 정보·체크섬·스냅샷 검증. 외부 서비스/DB에 접근하지 않는다.
- `validate.test.cjs`: 정상 배치 및 이미지 중복·원본 중복·잘못된 해시·라이선스 누락·없는 이미지·분량 오류·출처 길이 초과·공개 상태 변조·제목 초과의 10개 테스트 통과.

검증 명령:

```powershell
node server/content-batches/major-works-v9/build.cjs
node --test server/content-batches/major-works-v9/validate.test.cjs
```

모든 슬라이드의 실제 파일 존재와 SHA256 일치, 본문/출처 10,000자 제한, 제목 255자 제한, 편당 40장 제한, 각 글 이미지 원본 유일성, 14편 248장 합계를 확인했다. 앱·API·DB 실행이나 iPhone 실기기 검수는 하지 않았다. 일괄 배포 전에는 운영 중복 검사와 기존 글 보존, 마이그레이션 통합 테스트가 별도로 필요하다.

현재 작업 중 나타난 `.gitignore`와 `android/` 변경은 이 콘텐츠 작업의 산출물이 아니므로 건드리지 않았다. 이번 배치 전체는 로컬 작업 브랜치 `content/major-works-batch-v9`에 있으며 원격 게시하지 않았다.
